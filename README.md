### 👍 Toggle Like & Unlike

    A simple and interactive mini JavaScript project that allows users to toggle between Like and Unlike by clicking a button.

### ✨ Features

    - 👍 Toggle between Like and Unlike states
    - 🐶 Display images of a cute dog
    - 🖱️ Interactive button functionality
    - 🎨 Clean and simple user interface
    - ⚡ Real-time UI updates using JavaScript

### 🛠️ Technologies Used

    - HTML5
    - CSS3
    - JavaScript

### 📸 Project Preview

    The application displays a cute dog image with a Like button. When the user clicks the button, the interface switches between Like and Unlike states.

### 🚀 How to Run Locally

    1. Clone this repository:
   
    git clone https://github.com/kanithikalikowsik/js-toggle-like-unlike

    2. Open the project folder in VS Code.

    3. Open "index.html" in your browser.

    4. Click the button to toggle between Like and Unlike.
